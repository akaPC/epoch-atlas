# Epoch Atlas

Interactive atlas of human technological advancement, AGI/ASI forecasting, and 100-year projections.

Three movements:

1. **The Record**: every major technological epoch from the first stone tools to September 2026.
2. **The Threshold**: a multi-model forecast of AGI and ASI arrival with explicit assumptions and probability distributions.
3. **The Horizon**: field-by-field projections from 2026 to 2126, branched by takeoff scenario.

Static site. No backend, no database, no API keys. Built with Vite, React 18, TypeScript, Tailwind and D3.

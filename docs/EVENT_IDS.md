# Canonical event id registry

Every required event in The Record has a fixed id below. Content authors must use these ids exactly so that
`prerequisites`, `consequences` and Horizon `dependencies` resolve across epoch files. Authors may add extra
events beyond this list with new kebab-case ids.

Epoch ids (in order): `paleolithic`, `neolithic`, `bronze-age`, `iron-age-classical`, `medieval`, `print-scientific`,
`industrial-first`, `industrial-second`, `physics-total-war`, `atomic-space`, `microprocessor-pc`, `networked-world`,
`intelligence-era`.
